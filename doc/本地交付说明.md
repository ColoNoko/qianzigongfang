# 本地交付与构建说明

交付只保留 release/latest。程序包和源码包使用固定 latest 文件名。旧程序的用户 data 和迁移源码备份保留在 .local-backups，不进入交付包。

## 运行

Windows x64 便携版直接运行。应用数据保存在可执行文件旁的 data 文件夹；更新已有应用时保留原 data。交付包不包含开发机的数据库、漫画、字体缓存或设置。

## 从纯净源码构建

使用 Node.js 22.12 及以上的 22.x，按 package.json 指定的 pnpm 版本安装依赖：

```powershell
pnpm install --frozen-lockfile
pnpm exec tsc --noEmit -p tsconfig.node.json
pnpm exec vue-tsc --noEmit -p tsconfig.web.json
pnpm exec vitest run
pnpm exec electron-vite build
pnpm exec electron-builder --win portable --x64 --publish never
```

## 支持的本地交付命令

- `pnpm build:win:portable`：构建单文件 EXE 并导出源码 ZIP。
- `pnpm release:portable` / `pnpm release:win:portable`：先类型检查、全量单测及 lint，再构建单文件 EXE 和源码 ZIP。不会生成或上传远端更新清单。
- `pnpm build:win:unpack`：构建到 `release/latest/win-unpacked`。该目录仅供构建，不要直接作为日常运行目录或存放用户 data。
- `pnpm release:win:app`：只归档已构建的 `win-unpacked`，要求其中存在 `汉化工坊.exe`；不运行构建、不部署、不启动应用。
- `node scripts/deliver-windows.mjs --archive` 或 `--archive=zip`：与上一条一致，使用 Node 内置 ZIP 压缩，无需 7-Zip。不再产生 7z。
- `pnpm export:win-source`：导出纯净源码；`pnpm export:win-source --dry-run` 只列清单、无写入。文件夹归档也支持 `--dry-run`，需先有构建产物。
- `pnpm test:scripts`：只在临时目录验证文件排除、备份、旧包保留、缺失产物和错误路径。

固定产物：`release/latest/汉化工坊-latest-单文件版.exe`、`release/latest/汉化工坊-latest-文件夹版.zip`、`release/latest/qianzi-gongfang-source-latest.zip`。全部 package 构建命令使用 `--publish never`，不自动上传。

导出脚本先写临时 ZIP，再替换对应 ZIP；已有 ZIP 会先复制到 `.local-backups`。归档不包含任何层级的 data、logs、temp、.local-backups、数据库及备份文件，不跟随符号链接。它不会移动、删除或覆盖原程序目录和其中的 data。升级日常使用的程序前，请退出应用并自行备份原 data，再将程序文件解压覆盖；源码导出不是用户数据备份。

### 旧命令迁移

上游缺失的旧脚本没有完整实现可恢复，因此只保留可验证的本地交付流程：

- `watch:win-source` 已移除：改为修改完成后运行 `export:win-source`；不会后台持续覆盖交付包。
- `release:win:app:launch` / `deliver-windows.mjs --launch` 已停用：改用 `release:win:app`，审核后手动运行 EXE。
- `public:audit` / `public:sync` 已移除：缺失 `sync-public.mjs`，不假定公开仓路径或授权。`export:win-source --dry-run` 可检查本地导出清单，但不是密钥/隐私审计；公开发布前仍需人工检查源码与文档。
- `release:portable` 不再调用缺失的 `make-release.mjs`，改为上述带校验的本地发布构建。不修改根目录历史 `latest.json`，发布到服务器及更新清单需另行处理。

这些脚本的验证范围是本地文件操作；本次修复未执行 Windows 打包、程序启动、签名或远程发布。

## 源码包范围

包括 src、resources、build、scripts、doc、docs 和明确列入白名单的根目录构建配置、锁文件、许可证、README、AGENTS.md。根目录 `.env*` 不导出；`.npmrc` 仅允许当前公开的 `shamefully-hoist=true` 设置，出现其他设置即拒绝导出，需人工审核。私有源凭据应在目标机器单独配置。排除 .git、node_modules、out、release、temp、logs、.omo、数据库、缓存、增量编译产物和本地发布清单。

源码包不含安装好的依赖，首次编译需要下载依赖。可执行程序未做代码签名。

## 修复内容

1. 项目树：读取、合并快照、写入和前端水合检查父子节点形状；拒绝 null 节点、无效 children、缺失节点标识或目录等载荷。损坏读取明确报错，不再伪装空树；事务失败保留原值，原有损坏备份机制保留。存储策略的非数组 psdStats 缓存回落为空数组。
2. 图源预览：清空输入也使请求序号失效，并立即解除加载状态；晚到的结果不能恢复旧预览。
3. Photoshop：轮询绑定任务序号，旧回执不能覆盖新任务或停止新轮询；单次读取未完成时不叠加轮询；卸载后晚到的启动响应不能重启定时器。导出清单同样停止旧轮询，忙碌时阻止重复提交。
4. 回执读取：校验计数、任务标识、完成时间、警告数组和图片条目，异常/写到一半的回执返回 null，沿用进行中重试语义。
5. 操作结果：撤销、备份、恢复和清单生成之后的辅助日志失败不改变已成功的业务结果；显式 writeLog API 保留失败反馈。
6. openPath：系统调用拒绝时返回 E_OPEN_FAILED 和原始错误信息，避免调用方只处理结果对象却收到未处理拒绝。
7. 清理上一轮测试精简遗留的两处未使用 resolve 导入，使类型检查恢复通过。

# 模块化结构说明

2026-10-07，T12–T15。

## 入口与职责

- main/ipc/handlers.ts：组装各领域 IPC，不承载具体处理；原 preload 和共享 IPC 契约保持兼容。
- renderer/features/import：import-settings 为纯规则；import-form 为输入契约；useImportSource 管输入与匹配，useImportGeneration 管本地生成及预览，usePhotoshopJob 管外部任务。页面只组合这些实例，每个实例拥有自己的状态。
- renderer/features/project/useProjectViewer：预览会话、定时器、胶片订阅及预取释放。
- renderer/features/fonts：选择状态和虚拟列表；原 fonts/catalog 和 preview-loader 继续提供共享缓存。
- renderer/features/achievements：图表主题与实例管理；统计规则继续在 shared。
- renderer/stores/projectWorkspace.ts：兼容 store 与状态入口；workspace/*-actions 为职责分组，context 定义调用契约，helpers 为原有操作规则。
- shared/project-tree.ts：统一父子项目字段转换，显式区分展示快照与有效扫描缓存。后台项目树持久化仍由 project-repository 负责。
- main/services/directory-watch-pool.ts：同一路径的物理 watcher 和故障轮询；project-refresh 与 project-refresh-watch 是不同订阅用途的适配层。
- main/services/db：connection 管连接，schema 管表，values 管连接内键值读写，legacy-merge 管合并规则，legacy-snapshot 管 SQLite 来源读取，legacy-import 管启动迁移与手动导入事务。

## 依赖约束

共享规则不依赖 Electron、Vue 或页面；页面组合功能模块，模块不反向导入页面；数据库导入接受连接依赖，不回调导入 connection。缓存、worker 池、事务边界与存储键均沿用既有实现。避免继续向兼容入口堆业务。

## 验证范围

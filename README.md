# 汉化工坊（qianzi-gongfang）

给漫画汉化嵌字/翻译流程用的桌面工具：**选话 → 标进度 → 开外部软件干活**，把"这一本我干到哪了"这件事管清楚。

- 基于 **Electron + Vue 3 + TypeScript**，只在 **Windows** 上验证过（Linux/macOS 能构建，未实测）
- 数据都在**你自己的机器上**：单文件 SQLite + 备份，不上传、不联网（"检查更新"除外，见下）
- 许可证：**MIT**（见 `LICENSE`）

## 它能干什么

| 功能 | 说明 |
|---|---|
| 项目树 | 一本漫画 = 一个父级，一话 = 一个子项；扫描文件夹自动登记 |
| 四种工序 | 嵌字 / 翻译 / 校对 / 监修，**四条进度线互相独立**，一张图可以既"已翻译"又"已校对" |
| 标记 | 缩略图上点一下就是"这张做完了"；支持批量标记、撤销（Ctrl+Z）、标记台账 |
| 进度页 | 逐本欠账清单：更新至第几话、距上次**完整做完一话**多久、距上次**动手**多久、还欠几话 |
| 职责 | 给一本挂 1~2 个职责（"这本归我干哪道工序"），进这本时自动切到对应模式 |
| 外部工具 | 一键跳到 Photoshop（打开 PSD 或跑 .jsx 脚本）或 LabelPlusFX |
| 看图 | 对照模式：左边原图、右边 PSD，支持缩放 / 胶片条 / 自动播放 |
| 数据安全 | 自动 + 手动备份、逐条还原标记、诊断面板（版本 / 数据目录 / 日志） |
| 新手引导 | 内置说明书（首次启动自动弹，之后左下角「指引」随时再看） |

## 下载与安装（普通用户）

到 [Releases](https://gitee.com/Luo-yuan-z/qianzi-gongfang/releases) 下载最新版。有两种形态，**任选一种**：

| 形态 | 文件名 | 怎么用 |
|---|---|---|
| **文件夹版**（主推） | `汉化工坊-<版本>-文件夹版.7z` | 解压到一个**单独的空文件夹** → 双击里面的 `汉化工坊.exe`。启动快 |
| 单文件版 | `汉化工坊-<版本>-单文件版.exe` | 放哪儿都行，**双击即用**；不熟电脑的人首选 |

> ⚠️ 首次使用请解压到**单独一个空文件夹**，别直接解到桌面或下载目录那一堆文件里。

### 升级

1. 程序里 **设置 → 关于 → 检查更新** → 点「去下载」到下载页
2. **文件夹版**：把新包**解压到原来那个文件夹**，提示"是否覆盖"选**是**
3. **单文件版**：把新 exe **覆盖**原来那个 exe 就行

**你的标记数据在 `data\` 文件夹里，不在压缩包内，升级不会碰它** ✓

> ⚠️ 别解压到**新文件夹**：`data\` 是跟着文件夹走的，那样你会得到一份"空项目"的新副本
> （看起来像"我的项目不见了"，回到原文件夹就能看到数据）。

> **数据在哪**：程序第一次运行会在程序旁边建 `data/` 文件夹，里面有数据库与备份。
> 所以**程序与 `data/` 要在同一个文件夹里**，别把 exe 单独挪走。

## 从源码构建（开发者）

要求：Node 22.x、pnpm 11.x（`package.json` 里有 `engines` 约束）。

```bash
pnpm install

pnpm dev            # 开发模式（热更新）
pnpm test           # 全量单元测试
pnpm run typecheck  # tsc + vue-tsc
pnpm lint           # eslint

pnpm build:win:portable   # 单文件版（产物在 dist/）
node scripts/deliver-windows.mjs --archive   # 文件夹版（产物在 ../dist-packages/，需本机有 7-Zip）
```

Windows 打包会从 `npmmirror` 镜像下载 Electron（见 `electron-builder.yml` 的 `electronDownload.mirror`）；
海外环境删掉那段即回退官方源。

## 检查更新是怎么工作的

程序**只做"发现新版本 + 引导你去下载页"，不会自动下载或替换文件**：

1. 启动后（或你点「检查更新」时）拉一次 `latest.json`（本仓根目录，纯文本）
2. 比对版本号（按段比数字，`1.0.10` 比 `1.0.9` 新）
3. 有新版 → 显示版本号与更新说明，点「去下载」用系统浏览器打开下载页

断网 / 超时 / 清单坏了都只是"这次没查到"，不影响使用。
这一版**不写任何文件**（有测试锁着这条），也就绕开了未签名程序自动替换的风险。

## 数据与隐私

- 项目数据、标记记录、备份都在本机（`<exe 所在目录>/data/`）
- 程序只在"检查更新"时访问 `gitee.com` 拉那个 `latest.json`；不发送任何数据
- 日志在本机 `data/logs/`，诊断面板可一键复制（**里面的路径是你自己的，分享前看一眼**）
